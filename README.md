# white_Ihed_flower_inheritancce
## General Structure
The general structure of this repository is that all jobs are run from the jobs folder as the assumed working directory.

There are six main folders:
1. jobs: folder containing the job scripts. All scripts are labeled with a GOAL and a STEP number. For example, "GOAL2-Transcriptome_STEP1-read_alignment.sh" is the first step in the second goal of the project (transcriptome analyses).
2. raw_data: folder containing the raw input data for our analyses. We will direct you where to download the raw data which are then placed inside this folder. Unfortunately, the sequencing data is too large to be included in GitHub.
3. processed_data: folder where data processed and output by scripts are deposited.
4. manual_manifests: folder containing manifest files that are manually curated for use in the jobs scripts.
5. comp_env: folder containing the yaml and definition files for constructing our apptainer environments.
6. base_images: folder containing the raw_images by our R scripts before any small edits in image editing software.

Please note that we will load modules from the SLURM environment on Compute Canada and you may need to change those modules to reflect your system's set-up.

## jobs
 - **GOAL0-setup-environment_STEP1-apptainer-building.sh**: the goal of this script is to generate the Apptainers used in this project.
 - **GOAL1-Inheritance-Patterns_STEP1-statistics.Rmd**: RMarkdown script to determine inheritance pattern of white-flowered phenotype. The input data file is `../raw_data/flower_color_counts.csv` which contains the frequency count of white and purple pigmentation from an F2 generation. The output is a visualization of the inheritance patterns of the two phenotypes with annotations for a null expectation of a 3:1 inheritance pattern.
 - **GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh**: Shell script to process raw ORA files to produce soft-trimmed and hard-trimmed fastq files for input into STAR mapping.
 - **GOAL2-Transcriptome_STEP2-STAR-aligner.sh**: Shell script to align RNA-Sequencing reads to the Ipomoea hederacea genome using the STAR aligner. The most important output of this script is raw counts for each input fastq file to be used as input in a DESeq2 analysis.
 - **GOAL2-Transcriptome_STEP3-DESeq2_analysis.Rmd**: Differential expression analysis of RNA-Sequencing between white and purple flowers. Additionally, this script matches I. hederacea genes to potential homologs in tomato, Arabidopsis thaliana, or the closest relative in the KEGG database.
 - **pipeline_scripts**
    - **orad_decompression_fastqc_apptainer.sh**: Shell script called in `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh` to decompress, assess, and trim reads for sequencing.

## raw_data
 - **I_hederacea_v1.0.fa**: Genomic sequence of I. hederacea genome.
 - **ath00001.keg**: KEGG map of Arabidopsis thaliana.
 - **braker-202505.gtf**: Genome annotation of I. hederacea.
 - **flower_color_counts.csv**: Counts of pigment presence/absence in an F2 generation of purple/white-flowered crosses.

## processed_data 
 - **20250730_Ihed_index/**: Directory containing indexing of genome annotation generated by STAR in `GOAL2-Transcriptome_STEP2-STAR-aligner.sh`.
 - **20250730_rna/**: Decompressed fastq files from ORA. This was output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_rna_fastqc/**: FastQC assessment of raw sequencing files output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_rna_multiqc_raw/**: MultiQC summary of `20250730_rna_fastqc/` output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_rna_multiqc_trimmed/**: MultiQC summary of soft-trimmed reads in `20250730_rna_trimgal/` output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_rna_multiqc_trimmed_hard/**: MultiQC summary of hard trimmed reads in `20250730_rna_trimgal_hard3/` output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_rna_trimgal/**: Soft-trimmed reads output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_rna_trimgal_hard/**: Hard-trimmed reads at 5' end output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_rna_trimgal_hard3/**: Hard-trimmed reads at 5' and 3' ends output by `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **20250730_star_align_out/**: Aligned reads and gene counts output by `GOAL2-Transcriptome_STEP2-STAR-aligner.sh`.
 - **20250804_margaret_whitevpurple_significantDESeqgenes_LRT_araport11.tsv**: Significantly differentially expressed genes between white and purple flowers matched to Arabidopsis thaliana genes. This table is output by `GOAL2-Transcriptome_STEP3-DESeq2_analysis.Rmd`.
 - **20250807_arabidopsis_kegg_map.tsv**: Conversion of Arabidopsis thaliana KEGG map to tab-delimited file output by `GOAL2-Transcriptome_STEP3-DESeq2_analysis.Rmd`.

## manual_manifests
 - **20250806_Ihederaceae_araport11_diamondblastp_moresensitive.csv**: Pre-made DIAMOND search of annotated I. hederacea genes against Arabidopsis thaliana genes (Araport11).
 - **20250826_gentiana_3pGT_uniprot-q8h0f2_diamondblastp_moresensitive.txt**: Pre-made diamond search of 3'GT in Gentiana triflora because this gene is absent in A. thaliana.
 - **20250826_tomato_bz1_uniprot-A0A3Q7IMM2_diamondblastp_moresensitive.txt**: Pre-made diamond search of BZ1 in Solanum lycopersicum because this gene is absent in A. thaliana.
 - **20250826_tomato_f35h_uniprot-d3w9h7_diamondblastp_moresensitive.txt**: Pre-made diamond search of F3'5;H in Solanum lycopersicum because this gene is absent in A. thaliana.
 - **20250910_tomato_anthokegg_diamondblastp_moresensitive.txt**: Pre-made diamond search of critical genes in anthocyanin biosynthesis in Solanum lycopersicum searched against the I. hederacea genome.
 - **fastq_files.txt**: Manifest file of sequencing reads input into `GOAL2-Transcriptome_STEP1-quality-filtering-reads.sh`.
 - **manual_network_tables.ods**: Manifest ODS file for mapping known anthocyanin genes to KEGG IDs and EC IDs.
 - **rna_file_manifest_hard.txt**: Manifest file of processed sequencing reads for input into STAR alignment used by `GOAL2-Transcriptome_STEP2-STAR-aligner.sh`.

## comp_envs
 - **20250729_sickkids_decom-qual-trim.def**: Definition file for generating Apptainer for processing reads. Apptainer is generated by `GOAL0-setup-environment_STEP1-apptainer-building.sh`.
 - **20250730_aligners.def**: Definition file for generating Apptainer for aligning reads to I. hederecea genome. Apptainer is generated by `GOAL0-setup-environment_STEP1-apptainer-building.sh`.
 - **20250730_aligners.yml**: YAML file used in `20250730_aligners.def`.
 - **orad.2.7.0.linux/**: Executable directory of DRAGEN ORAD software.
 - **oradata/**: Input reference files needed for decompressing .ora files using the DRAGEN ORAD software.
 - **quality_and_trim_py3.yml**: YAML file used in `20250729_sickkids_decom-qual-trim.def`.
